# data/

Put your **private** placement policy PDFs here if you want to keep them next to the project
(for example, while testing). Everything in this folder except this README is git-ignored.

Documents only become searchable after an administrator uploads them through the
**Documents** page (or `POST /documents/upload`). Files placed here are *not* indexed automatically.

Do not commit real policy documents, circulars, or the generated vector database
(`backend/.chroma/`) to a public repository.
